## Brewリスト - お気に入りMacアプリの内訳

[Brewfile][brewfile]を使えば、これらのアプリをHomebrewでインストールできます。

> [!NOTE]
> BrewfileにはVS Codeの拡張機能とGoモジュールも含まれています。これらはページ末尾のBrewfileにすべて記載していますが、このリストでは個別に紹介していません。


### 生産性とユーティリティ

* `alfred` - **Alfred** - アプリの起動、ファイル検索、ワークフローの自動化ができる生産性アプリです。
* `grammarly-desktop` - **Grammarly** - 文法、スペル、文体の提案をしてくれるデスクトップ版のライティングアシスタントです。
* `iterm2` - **iTerm2** - 分割ペイン、ホットキーなどを備えたmacOS用の高機能ターミナルエミュレーターです。
* `jordanbaird-ice` - **Ice** - メニューバーの項目を隠したり、並べ替えたり、カスタマイズしたりできるメニューバー管理アプリです。
* `karabiner-elements` - **Karabiner-Elements** - macOSでキーをリマッピングできる強力なキーボードカスタマイザーです。
* `keycastr` - **KeyCastr** - デモ、スクリーンキャスト、プレゼンテーション用にキーストロークを可視化します。
* `logi-options+` - **Logi Options+** - Logitech（ロジクール）のマウスとキーボード用の設定ソフトウェアです。
* `macupdater` - **MacUpdater** - macOSアプリの新しいバージョンをチェックして最新の状態に保ちます。
* `pareto-security` - **Pareto Security** - Macの基本的なセキュリティ状態を自動で監査します。
* `rocket` - **Rocket** - どこでもすぐに絵文字を入力できるシステム全体の絵文字ピッカーです。
* `setapp` - **Setapp** - 厳選されたMacアプリを利用できるサブスクリプション型のアプリライブラリです。
* `taphouse` - **Taphouse** - Homebrewのパッケージを管理するネイティブのGUIアプリです。


### AIツール

* `chatgpt` - **ChatGPT** - OpenAI公式のChatGPTデスクトップアプリです。
* `chatgpt-atlas` - **ChatGPT Atlas** - ChatGPTを組み込んだOpenAIのWebブラウザです。
* `claude` - **Claude** - Anthropic公式のClaudeデスクトップアプリです。
* `claude-code` - **Claude Code** - Anthropicが提供する、ターミナルで使うAIコーディングアシスタントです。
* `codex` - **Codex** - ターミナルで動くOpenAIのコーディングエージェントです。
* `codex-app` - **Codex App** - Codexのコーディングエージェントを管理するOpenAIのデスクトップアプリです。
* `cursor` - **Cursor** - コードの作成、編集、コードについてのチャットができるAI搭載のコードエディターです。
* `lm-studio` - **LM Studio** - ローカルLLMを探してダウンロードし、手元のマシンで実行できます。
* `openvino` - **OpenVINO** - AI推論のためのOpen Visual Inference and Optimizationツールキットです。


### Webブラウザ

* `firefox` - **Firefox** - プライバシーとカスタマイズに特化したオープンソースのWebブラウザです。
* `google-chrome` - **Google Chrome** - Googleが開発した高速で安全なWebブラウザです。


### コミュニケーションとコラボレーション

* `discord` - **Discord** - コミュニティやゲーム向けの音声、ビデオ、テキストチャットプラットフォームです。
* `slack` - **Slack** - メッセージング、ファイル共有、各種サービス連携ができるコラボレーションハブです。
* `google-drive` - **Google Drive** - Google Driveクラウドストレージのファイルを同期、アクセスするデスクトップクライアントです。
* `notion` - **Notion** - 文章作成、計画、共同作業、整理をひとつでこなせるオールインワンのワークスペースです。


### デザインとメディア

* `figma` - **Figma** - UI/UXプロトタイピング向けのコラボレーションインターフェイスデザインツールです。


### エンターテインメント

* `spotify` - **Spotify** - 膨大な楽曲とポッドキャストを楽しめる音楽ストリーミングアプリです。
* `vlc` - **VLC media player** - ほぼすべてのオーディオとビデオのフォーマットに対応する多機能マルチメディアプレーヤーです。


### 開発ツール

* `visual-studio-code` - **Visual Studio Code** - 拡張機能とGit連携を備えた多機能ソースコードエディターです。
* `github` - **GitHub Desktop** - GitリポジトリとGitHubのワークフローを管理するGUIクライアントです。
* `gh` - **GitHub CLI** - ターミナルからGitHubを操作できるコマンドラインツールです。
* `bash` - **Bash** - 広く使われているUNIXのコマンドインタープリター、GNU Bourne-Again SHellです。
* `curl` - **curl** - HTTP、HTTPS、FTPなどでサーバーとデータを送受信します。
* `ffmpeg` - **FFmpeg** - 数多くのフォーマットの音声と動画を録画、変換、配信します。
* `fzf` - **fzf** - Go言語で書かれたコマンドラインのあいまい検索ツールです。
* `go` - **Go** - シンプルで信頼性が高く、効率のよいソフトウェアを作るためのオープンソースのプログラミング言語です。
* `jq` - **jq** - 軽量で柔軟なコマンドラインのJSONプロセッサーです。
* `nodenv` - **nodenv** - 複数のNode.jsバージョンを管理、切り替えできます。
* `node-build` - **node-build** - Node.jsのバージョンをインストールするためのnodenvプラグインです。
* `pyenv` - **pyenv** - 複数のPythonバージョンをシームレスにインストール、管理できます。
* `pipx` - **pipx** - Pythonのコマンドラインアプリを、独立した環境にインストールして実行します。
* `uv` - **uv** - Rustで書かれた、非常に高速なPythonパッケージインストーラー兼リゾルバーです。
* `rustup` - **rustup** - Rustツールチェーンのインストーラー兼バージョン管理ツールです。
* `php` - **PHP** - Web開発向けの汎用スクリプト言語です。
* `pnpm` - **pnpm** - 高速でディスク容量を節約できるNode.js用のパッケージマネージャーです。
* `pre-commit` - **pre-commit** - 複数の言語に対応したGitのpre-commitフックを管理するフレームワークです。
* `tree` - **Tree** - ディレクトリ構造をツリー形式で表示します。
* `csvkit` - **csvkit** - CSVへの変換とCSVの操作ができるコマンドラインツール群です。
* `phrase-cli` - **Phrase CLI** - PhraseのローカリゼーションAPIを操作するコマンドラインツールです。
* `cjson` - **cJSON** - ANSI Cで書かれた超軽量のJSONパーサーです。
* `nss` - **NSS** - セキュリティ機能を持つアプリケーション向けのNetwork Security Servicesライブラリです。
* `pkgconf` - **pkgconf** - パッケージのコンパイラーとリンカーのメタデータを扱うツールキットです。


#### Markdownとドキュメントのツール

* `pandoc` - **Pandoc** - 複数のマークアップフォーマットに対応するユニバーサルドキュメントコンバーターです。
* `qlmarkdown` - **QuickLook Markdown** - Markdownファイルをクイックルックでライブプレビューできるようにします。
* `macdown` - **MacDown** - ライブプレビューとシンタックスハイライト付きのMarkdownエディターです。
* `lychee` - **Lychee Link Checker** - MarkdownとHTMLファイル向けの高速リンクチェッカーです。
* `markdownlint-cli2` - **markdownlint-cli2** - 設定ファイルにもとづいてMarkdownファイルをリントする高速なCLIです。
* `github-markdown-toc` - **GitHub Markdown TOC** - Markdownドキュメントの目次を生成します。
* `vale` - **Vale** - 構文を理解して文章とドキュメントをチェックするリンターです。


### フォント

* `font-fira-code` - **Fira Code** - コードを見やすくするプログラミングリガチャ付きの等幅フォントです。
* `font-fira-code-nerd-font` - **Fira Code Nerd Font** - Nerd FontのグリフとアイコンでパッチしたFira Codeです。
* `font-hack-nerd-font` - **Hack Nerd Font** - 開発用の追加グリフを含むパッチ済みフォントです。
* `font-hackgen` - **HackGen** - Hackと源柔ゴシックを合成した日本語プログラミングフォントです。
* `font-opendyslexic-nerd-font` - **OpenDyslexic Nerd Font** - Nerd Fontアイコン付きのディスレクシアに配慮したフォントです。
