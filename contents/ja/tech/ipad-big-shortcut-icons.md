## 概要

* このガイドでは、iPadのホーム画面に大きな画像を置き、タップするとiOSのショートカットを実行する方法を説明します。
* 目的は、ショートカットアプリの標準アイコンではなく、大きくタップできるアイコンを追加することです。
* 無料の[Scriptable][scriptable]アプリと、短いJavaScriptのウィジェットスクリプトを使います。
* 対象は、すでにショートカットを使っていて、ホーム画面の起動用アイコンを大きくしたいiPadユーザーです。


## 事前準備


### Scriptableをインストールする

1. iPadでApp Storeを開きます。
2. **Scriptable**を検索し、[Scriptable][scriptable-app-store]をインストールします。

ScriptableはiPad上でJavaScriptを実行し、ホーム画面のウィジェットを描画します。


### ショートカットを作成または選択する

1. **ショートカット**アプリを開きます。
2. 新しいショートカットを作成するか、既存のショートカットの正式名称を控えます。
3. この手順では`Example Shortcut`と名前を付けるか、今の名前のままにして、あとでスクリプトを更新します。

ウィジェットは名前でショートカットを開きます。スクリプト内の文字列は、ショートカットアプリの名称と完全に一致させてください。


### ウィジェット用の画像を用意する

ウィジェットのサイズでも内容が読み取れる、正方形かそれに近い画像を選びます。iPadで大きなアイコンのように見せるには、中サイズまたは大サイズのホーム画面ウィジェットが向いています。


## 大きなショートカットアイコンを追加する手順


### Step 1：Scriptableのスクリプトを追加する

1. **Scriptable**を開きます。
2. **+**をタップして、新しいスクリプトを作成します。
3. 下の[ウィジェットスクリプト](#widget-script)をエディタに貼り付けます。
4. ショートカット名が`Example Shortcut`でない場合は、スクリプト上部の`SHORTCUT_NAME`を変更し、ショートカットアプリの名称と完全に一致させます。
5. **Done**または閉じるボタンをタップして、スクリプトを保存します。
6. Scriptable上のスクリプト名を、`Example Shortcut icon`のように、あとから見分けられる名前に変更します。

> [!CAUTION] 注意：画像を選んだあとにスクリプト名を変えない
> 保存される画像はスクリプト名で保存されます。名前を変えると画像を見つけられなくなり、ウィジェットに「Open Scriptable and run this script once.」が再び表示されます。名前を変えた場合は、スクリプトを再実行して画像を選び直してください。


### Step 2：ウィジェットの画像を選ぶ

1. Scriptableでスクリプトを開きます。
2. **Play**ボタンをタップして、アプリ内で実行します。
3. 写真の選択画面が表示されたら、用意した画像を選びます。
4. Scriptableがプレビューサイズを尋ねたら、**Medium**または**Large**など、追加するウィジェットのサイズを選びます。
5. Scriptableが表示するプレビューを確認します。

Scriptable内でスクリプトを1回実行すると、画像がウィジェット向けのサイズに縮小され、Scriptableのローカルファイルに保存されます。ホーム画面のウィジェットには、この保存ファイルが必要です。


### Step 3：ホーム画面にScriptableウィジェットを追加する

1. iPadのホーム画面で、何もない場所を長押しし、アプリが揺れるまで待ちます。
2. 左上の**編集**をタップし、**ウィジェットを追加**をタップします。
3. **Scriptable**を検索し、**中**または**大**のウィジェットサイズを選びます。
4. **ウィジェットを追加**をタップし、**完了**をタップします。
5. 新しいウィジェットを長押しし、**ウィジェットを編集**をタップします。
6. **Script**を、作成したスクリプトに設定します。
7. Scriptableのパラメータをすでに使っている場合を除き、他のオプションは初期設定のままにします。
8. 設定画面の外側をタップします。ホーム画面がまだ編集モードなら、**完了**をタップします。

ウィジェットに選んだ画像が表示されます。タップすると、`SHORTCUT_NAME`に書いた名前のショートカットが実行されます。

## 補足情報

* アイコンを増やすには、ショートカットごとにScriptableでスクリプトを複製します。複製ごとに固有の名前と`SHORTCUT_NAME`を付け、それぞれ1回実行して画像を選びます。画像はスクリプト名ごとに保存されるため、ウィジェット同士で上書きしません。
* 画像をあとから変えるには、Scriptableでスクリプトを開き、再実行します。写真の選択画面で保存済みの画像が置き換わり、次の更新でウィジェットに反映されます。今の画像を置き換えずにプレビューするには、写真の選択をキャンセルします。
* 同じスクリプトを、小、中、大のScriptableウィジェットで使えます。中と大は、iPadの大きなアプリアイコンに最も近く見えます。


## トラブルシューティング


### ウィジェットに「Open Scriptable and run this script once.」と表示される

保存された画像がまだないか、画像を保存したあとにスクリプト名を変更しています。Scriptableでスクリプトを開き、**Play**で実行して、画像を選びます。


### ウィジェットをタップしても何も起きない、または別のショートカットが実行される

`SHORTCUT_NAME`がショートカットアプリの名称と、大文字と小文字、および空白も含めて一致しているか確認します。ショートカット側か定数側の名前を揃え、スクリプトを保存してから、ウィジェットを編集してスクリプトを選び直します。


### ウィジェットが空白になる、または古い画像が表示される

1. Scriptable内でスクリプトを1回実行し、保存画像を書き直します。
2. ウィジェットを長押しして**ウィジェットを編集**をタップし、正しいスクリプトが選ばれているか確認します。
3. それでも更新されない場合は、iPadを再起動します。


### Scriptableが写真へのアクセスを求める

表示されたら、写真へのアクセスを許可します。アプリ内の実行は`Photos.fromLibrary()`でウィジェット画像を選びます。
